# 📝 HRText Editor

HRText Editor is a simple 🖊️ text editor built with 🐍 Python and 🎨 Tkinter. It lets users ✍️ create, ✂️ edit, 💾 save, and 📂 open text files easily.

---

## ⭐ Features
- ✨ Create and edit text files
- 📂 Open and save files
- 💾 "Save As" for renaming
- 🎯 Simple and lightweight UI

## 🛠️ Installation
1. Ensure 🐍 Python 3️⃣.x is installed.
2. 📥 Clone the repo:
   ```sh
   git clone https://github.com/RamezHas/hrtext-editor.git
   cd hrtext-editor
   ```
3. 🎨 Install Tkinter if needed:
   ```sh
   pip install tk
   ```
4. ✅ Ready to use!

---

## 🚀 How to Use
Run the script:
```sh
python text_editor.py
```
Use the 📜 menu to create, open, and save files. "Save As" allows renaming.
